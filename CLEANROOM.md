# ARMATURA provenance and independent-implementation procedure

ARMATURA is **independently implemented from public specifications and papers; competitor feature lists were consulted for scope; no third-party source code was copied.** It is not "clean-room" in the strict legal sense (no separate team wrote a specification for a second team), and this file says what was and was not done. Not legal advice; an engineering discipline that keeps provenance auditable.

## Rules
1. **Inputs allowed**: public standards (RFCs, W3C, WCAG, PNG/APNG, OpenRaster, OCA, Lottie spec), textbooks and peer-reviewed papers older than their patents' scope, public documentation and *user-visible* behaviour of products.
2. **Inputs forbidden**: decompiled or disassembled code, leaked sources, proprietary file-format reverse engineering, EULA-restricted SDKs, vendor model weights, other products' icons, names, UI strings or sample content.
3. **Provenance recorded per module**: the method and its public source (standard, paper, textbook) are named in the module's doc comment and in the log below. A separate written spec note per feature (template at the end) was **not** produced before implementation for most modules; this procedure does not claim it was. Where a module follows one published algorithm closely, the log says so.
4. **Own names and schema** for anything without a public standard. Don't copy product terminology.
5. **Patent screen** before shipping any 🟡 item; prefer a different algorithm over a design-around. The screening still undone is listed in docs/PATENT_NOTES.md (not legal advice).
6. **Dependencies**: permissive licences only (MIT/Apache/BSD/Zlib/ISC/Unlicense/CC0); log each in the table below. One exception: the `scripting` feature (a Cargo feature that is ON by default in `armatura-core` and `armatura-cli`; `--no-default-features` turns it off) pulls `rhai`, which pulls `smartstring` (MPL-2.0+, file-level copyleft). It is allowed by name in `deny.toml`; a build with `--no-default-features` contains no MPL third-party crate (checked per package at the end of docs/THIRD_PARTY.md).

## Research disclosure
The feature research behind FEATURES.md was done by an AI research agent that looked at public repositories, changelogs and documentation of other tools for **feature ideas and scope only**: rive-runtime, spine-runtimes, Pencil2D, Glaxnimate, Friction, and Live2D-compatible editors, plus the public feature lists of commercial products. The author cannot attest that the research agent read no source code in those repositories; no code, tables, constants, identifiers or file formats from them were intentionally used, and the implementation was written separately from public specifications, papers and textbook mathematics. Code in this repository was also largely written with an AI model (see LICENSING.md on authorship); its training data is not under the author's control. A reviewer who needs stronger assurance should treat this as an independent implementation with a documented residual risk, not as a clean-room guarantee.
