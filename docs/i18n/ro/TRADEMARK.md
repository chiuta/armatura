# Politica privind numele și logo-ul ARMATURA

Licențele din LICENSE acoperă codul, nu numele „ARMATURA” și nici vreun logo. (Verifică disponibilitatea mărcii înainte de lansare; „armatura” este și un cuvânt obișnuit în română/italiană.)

Permis fără a cere acordul: să spui că software-ul tău este „compatibil cu ARMATURA” sau „realizat cu ARMATURA”; redistribuirea unei versiuni nemodificate sub numele original; trimiterea către proiect printr-un link.

Nepermis fără acord: distribuirea unei versiuni modificate sub numele ARMATURA sau într-un mod care sugerează că este oficială; folosirea numelui sau a logo-ului drept nume al propriului produs sau al propriei companii.
