# Política del nombre y el logotipo de OSATURA

Las licencias de LICENSE cubren el código, no el nombre «OSATURA» ni ningún logotipo. (Disponibilidad de la marca: véase docs/LIMITATIONS.md L-78; «osatura» es también una palabra corriente en rumano que significa esqueleto o armazón.)

Permitido sin pedir autorización: decir que tu software es «compatible con OSATURA» o «hecho con OSATURA»; redistribuir una compilación sin modificar bajo el nombre original; enlazar al proyecto.

No permitido sin permiso: distribuir una compilación modificada con el nombre OSATURA o de un modo que sugiera que es oficial; usar el nombre o el logotipo como nombre de tu propio producto o empresa.
