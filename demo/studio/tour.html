Guided demo · Buddy

Build a whole character, step by step, with the same commands you would type in a terminal. Each step loads the project that command produced into this editor, so you can play, scrub, select bones and layers, and look at the timeline.

This replaces the project in the editor. Nothing is written to disk: Save is disabled while the demo is loaded, and Restore my project (or Undo) brings your project back.
